## 👨‍💻 About Me

I build applications at the intersection of **Artificial Intelligence** and **Full-Stack Engineering**.

My strongest project is **MERS (Multimodal Emotion Recognition System)** — a deep learning pipeline built in **PyTorch** that combines text, audio, and visual modalities through a late-fusion architecture. The system leverages:

- 📝 Text Understanding (BERT)
- 🎙️ Audio Processing (Conv1D + BiLSTM)
- 🎥 Visual Feature Extraction
- 🔗 Late Fusion Architecture

Trained on the **TESS dataset**, MERS sits at the crossroads of **Natural Language Processing**, **Signal Processing**, **Computer Vision**, and **Applied Machine Learning**.

Alongside traditional machine learning, I'm actively exploring modern **LLM application development**, including:

- Retrieval-Augmented Generation (RAG)
- LangChain
- LangGraph
- Vector Databases
- AI Agents
- Prompt Engineering
- LLM-Powered Applications

On the full-stack side, I've built **Bookshelf**, a production-ready MERN application featuring JWT authentication, protected routes, REST APIs, and cloud deployment.

Currently strengthening my DSA foundations and preparing for **Software Development Engineer (SDE)** and **Machine Learning Internship** opportunities for 2026.
